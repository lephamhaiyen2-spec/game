# Game ghép hình tế bào – KHTN 6

Trò chơi tương tác dành cho học sinh lớp 6: ghép 20 mảnh để hoàn thành hình **tế bào thực vật**, **tế bào động vật** hoặc **tế bào nhân sơ**.

## Nội dung
- 3 trò chơi riêng, mỗi trò 20 mảnh puzzle.
- Hình minh họa phong cách 3D, màu sắc sinh động.
- Mức độ kiến thức đơn giản: màng tế bào, tế bào chất, nhân (ở tế bào nhân thực).
- Mảnh ghép có khớp lồi/lõm mô phỏng puzzle.
- Kéo mảnh vào vị trí; mảnh đúng vị trí sẽ tự khớp.

## 3 trò chơi
- `plant.html` – Tế bào thực vật
- `animal.html` – Tế bào động vật
- `prokaryotic.html` – Tế bào nhân sơ

Mở các file HTML trực tiếp trong trình duyệt để chơi.
